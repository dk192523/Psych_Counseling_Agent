## 范围与剩余工作

- F2 的窗口沿用既有安全提示词的 **6 条消息（约 3 轮）**：基于数据库历史，模式切换和进程重启不丢失；风险移出窗口后停止历史风险检查。它修复提示词与输出层不一致，**不代表已经建立经过专业评审的风险解除标准**。没有把历史 IMMINENT 永久强制成危机模板。
- `[DONE]` 现在在模型正文中完全按文字处理。HTTP SSE 的 JSON `type=done` 合约不变，客户端无需迁移；进程内调用 prepared 方法的代码不得再期待文本结束哨兵。
- 凭据版本使用现有带盐密码哈希的相等性，不新增数据库列，也不把哈希加入会话 principal 或 API DTO。单副本限制继续有效。
- 检索质量 R2、敏感数据保护与真实部署 R3、完整 E2E/容量/可观测性 R4 仍未验收通过。需要独立相关性标注、真实环境与相应验证，不能由上述缺陷修复或增加单测数量代替。
- 所有权、幂等、回答事务归档、取消/部分回放、危机模板的原有回归均继续运行；本轮没有重建向量库或修改已有咨询正文。
