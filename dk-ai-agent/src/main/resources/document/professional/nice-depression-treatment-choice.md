# 抑郁评估与治疗选择：共同决策的概念

资料类型：项目原创中文专业知识摘要。参考英国 NICE NG222 建议，不是指南译文，也不代表 NICE 授权或认可本系统。

抑郁的识别与评估需要结合症状、持续时间、功能影响、既往病程及相关背景，不能把量表总分当作全部信息。治疗选择需要讨论个人需要、偏好、既往治疗体验，以及不同方案的可能获益、风险和实施条件。

CBT 是一种结构化心理干预，关注想法与行为如何影响情绪，并通过共同设定目标和练习学习应对方法。把某条消极想法换成积极口号，不等于完整的 CBT；阅读知识摘要或做一道题，也不等于接受了心理治疗。

“共同决策”意味着专业人员和当事人讨论可选方案及其依据，帮助作出知情选择，并随情况变化回顾效果。它既不意味着由系统指定唯一方案，也不意味着忽略安全需要。不能只凭一个症状、一道题或某个评分给个人开药、停药或确定疗程。

适用范围与限制：供学习英国指南中的评估与治疗选择原则。NICE NG222 是英国指南，不能当作中国法律、当地医疗服务承诺或个体处方；实际治疗需由合格专业人员结合当地规范与具体情况决定。复习时要区分“描述某干预的原理”与“为个人选择治疗方案”。
