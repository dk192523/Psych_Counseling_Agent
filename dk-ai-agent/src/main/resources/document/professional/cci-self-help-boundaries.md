# 自助练习与情绪觉察

资料类型：项目整理的原创科普摘要（curated summary）。以 CCI 公开自助资源的定位为参考，不复制其工作簿，不构成诊断或个体化治疗。

CCI 提供面向不同心理困扰的自助材料，并说明材料不能替代合格专业人员的诊断和治疗。阅读某一主题的材料，不意味着读者符合相应疾病的诊断标准。

本项目可邀请用户用自己的话区分发生的事情、当时的想法、情绪和行为，再一起选择一个容易执行的小步骤，例如记录压力情境或联系可信任的人。练习应尊重意愿，效果因人而异；感到负担加重时可以暂停。不要承诺一次练习消除焦虑，也不要根据练习结果为用户贴标签。
