# 抑郁：症状描述与临床诊断的区别

资料类型：项目原创中文科普摘要。参考 NIMH 抑郁科普资料，不复制原文，不代表该机构授权或背书。

持续低落、兴趣或愉悦感下降，以及睡眠、食欲、精力或注意力的变化，可能出现在抑郁相关困扰中，但这些表现并非抑郁所独有。短暂的低落不等于抑郁障碍；有一个症状也不能直接推出诊断。

专业评估不仅了解症状种类，还会考虑持续时间、频率、严重程度、对学习工作和生活的影响，以及身体状况、药物因素和既往经历等可能解释。科普中提到的持续时间是理解评估的线索，不是自助计时确诊的规则，也不是必须等满某个时限才能求助。

筛查用于提示进一步了解的需要，不能单凭一个量表分数代替诊断。复习题目时，应区分“描述了某种表现”“提示需要评估”与“已经确诊”三个层次；信息不足时不能补造病史或从单一表现断定疾病。

适用范围与限制：供识别概念与理解求助时机，不提供个体诊断、用药或排除疾病的结论。症状持续、令人困扰或影响生活时，可与专业人员讨论；严重痛苦不需要先满足自拟的时间门槛才寻求帮助。
