# CBT：自动思维与思维记录

资料类型：项目原创中文知识摘要。参考 CCI 焦虑自助资源，不是原文翻译、工作簿复制或机构授权材料。

认知行为疗法（CBT）关注想法、情绪和行为之间的联系。同一情境可能引出不同解释，进而影响感受与应对。“自动思维”指情境中快速出现的想法或意象，它看似可信，但不自动等于事实。焦虑也涉及身体反应与环境因素，不能把所有痛苦归因于“想错了”。

思维记录可按以下顺序理解：先写可观察的情境，再分别记录自动思维、情绪及强度、身体反应和行为；随后寻找支持与不支持该想法的证据，提出更平衡、贴近事实的解释，最后重新观察情绪与可行的行动。记录的目的在于理解和检验解释，不是强迫自己乐观，也不要求情绪立即消失。

辨析例子：“任务还未完成”描述情境；“这证明我永远做不好”是解释；“担心”是情绪；“反复拖延”是行为。这个例子是概念示意，不是个人病例。复习时先区分事实、推测、感受和行动，再判断选项是否允许检验证据，避免把积极口号当成认知重评。

适用范围与限制：用于概念学习和自愿的日常觉察。自助材料不能替代专业诊断或治疗；练习引发明显负担时可以暂停。持续困扰或功能受损应与合格专业人员讨论，不凭一张记录表判断疾病。
