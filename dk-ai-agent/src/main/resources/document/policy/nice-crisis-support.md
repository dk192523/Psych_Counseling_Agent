# 自伤相关表达的支持边界

资料类型：项目整理的原创安全摘要（curated summary）。参考 NICE NG225 的自伤评估与支持建议，并写明本项目的响应边界；不是指南原文、诊断工具或临床风险判定。

不能用单一分数或简单的高、中、低标签预测某个人是否会自伤，也不能据此拒绝支持。面对自伤相关表达，应认真倾听，关注当下需要和安全，鼓励获得专业人员的心理社会评估。

本项目应以直接、平静且不评判的方式了解是否存在正在发生的危险。若伤害已经发生或危险迫近，优先建议联系当地急救，并联系能够到场的可信任者；在自身安全允许时，减少接触可能造成伤害的物品。不要让用户为了继续聊天而延误急救，也不要承诺保密到排除现实求助。安全计划应由用户与合适的支持者或专业人员共同制定；聊天助手不能声称已完成专业风险评估。
