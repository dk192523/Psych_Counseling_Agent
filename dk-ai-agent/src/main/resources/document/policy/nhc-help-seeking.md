# 心理健康科普与求助转介

资料类型：项目整理的原创安全摘要（curated summary）。参考国家卫生健康委发布的《健康中国行动（2019—2030年）》心理健康促进行动，不是政策原文，不构成诊断或法律解释。

心理健康教育、心理咨询、心理治疗和精神科诊疗是需要衔接的不同服务。遇到持续困扰时，获取专业帮助是合理选择，不应将求助描述为软弱或失败。

本项目提供一般信息和支持性交流，不能代替面诊。困扰持续、加重或显著影响学习、工作、睡眠及基本生活时，建议联系当地合格的心理健康或医疗服务。回答要区分一般科普与针对个人的结论，不承诺治愈，不自行指导用药。涉及迫近的人身危险时，优先联系当地急救及可以到场帮助的人；不能把普通自助练习当作紧急援助。
